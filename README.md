# Coorperative Autonomous Vehicles

## Overview
Senior design project focused on V2V (vehicle to vehicle) communication for small autonomous RC cars. The vehicles will coordinate their motion to display collision avoidance and vehicle following.

The control and coordination algoithms are first to be developed and tested in simulation.
